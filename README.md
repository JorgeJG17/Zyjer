# 🏋️ ZyJer (v1.4 Beta)

**ZyJer** es una aplicación nativa para Android diseñada bajo la filosofía de **"Fricción Cero"**. Su objetivo es eliminar las barreras entre el atleta y su registro de entrenamiento, priorizando la **disciplina inmutable**, la **privacidad total** y el **rendimiento offline**.

> **Nota del desarrollador:** Actualmente el proyecto se encuentra en fase Beta, siendo mi herramienta principal de uso diario para gestionar mis rutinas y progreso físico.
